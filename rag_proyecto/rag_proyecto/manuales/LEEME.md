# Manuales (no se versionan)

Los PDF se descargan del sitio oficial de soporte de Samsung y se colocan en esta carpeta.
`ingest.py` asigna el título de cada manual según el prefijo del nombre del archivo:

| Prefijo del archivo | Manual |
|---|---|
| `SM-L32X…` | Galaxy Watch8 / Watch8 Classic user guide |
| `SM-S93X…` | Galaxy S25 / S24 series user guide |
| `SM-X21X…` | Galaxy tablet SM-X210 / X216B / X218B user manual |

Archivos usados en el proyecto (en inglés):

- `SM-L32X_L33X_L50X_UG_EU_Android_Eng_Rev_1_1_250718.pdf`
- `SM-S93X_S92X_UG_LTN_16_Eng_Rev_1_0_250915.pdf`
- `SM-X21X_UM_EU_TT_Eng_Rev_1_0_230922.pdf`
